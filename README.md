# Credit_Card_Revenue-Customer_Analytics

## Project Description

The Credit Card Customer & Transaction Analysis project is developed using Python, Pandas, SQL, and Power BI to analyze customer behavior, transaction trends, and revenue performance through interactive dashboards.

The project includes:

* **Customer Report Dashboard** – analyzes customer demographics, income groups, spending behavior, and revenue trends.
* **Transaction Report Dashboard** – analyzes transaction amount, transaction count, card category performance, interest earned, and transaction methods.

---

## Problem Statement

Financial institutions generate large amounts of customer and transaction data, making manual analysis difficult. This project helps analyze customer spending patterns, revenue trends, and transaction behavior efficiently using data analytics and visualization.

---

## Technologies Used

* Python
* Pandas
* SQL
* Power BI
---

## Dashboard Explanation

The dashboards provide insights into:

* Revenue analysis
* Transaction trends
* Customer demographics
* Card category performance
* Spending behavior
* Interest earned
* Customer acquisition cost

Interactive filters allow detailed customer and transaction analysis.

---

## Business Insights

The analysis showed that Blue card customers generated the highest revenue, swipe transactions were the most used transaction method, and high-income customers contributed significantly to revenue and interest earned.

---

## Conclusion

This project demonstrates how customer and transaction data can be transformed into meaningful business insights using analytics and visualization tools to improve customer analysis, revenue optimization, and business decision-making.
